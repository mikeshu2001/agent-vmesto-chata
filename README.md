# Курс: агент вместо чата

Короткий практический курс. Вы приходите со своей настоящей задачей, а агент-тьютор ведет вас по урокам прямо в рабочей папке: уже в первом уроке появится готовая вещь для вашей работы.

Понадобится установленный Codex или Claude Code.

## Как начать

**Способ 1 — через агента.** Скопируйте ссылку на этот репозиторий и напишите своему агенту: «Скачай курс по ссылке https://github.com/mikeshu2001/agent-vmesto-chata в новую папку». Когда он закончит, откройте программу в папке курса и напишите: **начни курс**.

**Способ 2 — руками.** Нажмите Code → Download ZIP, распакуйте архив, откройте папку в Codex или Claude Code и напишите: **начни курс**.

## Как вернуться после перерыва

Откройте эту же папку и напишите: **продолжи курс**. Карточка прогресса напомнит агенту, кто вы и где остановились.
